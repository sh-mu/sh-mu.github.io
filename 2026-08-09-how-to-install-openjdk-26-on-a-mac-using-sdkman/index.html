How to Install OpenJDK 26 on a Mac Using SDKMAN

Welcome to the “blog-posts” series! If you are a developer using a Mac, setting up Java should be quick and easy. In this post, I will show you how to install OpenJDK 26 using a great tool called SDKMAN.

This guide uses clear and simple English, so it is easy to follow for developers everywhere.

What is SDKMAN?

SDKMAN! stands for Software Development Kit Manager.

It is a free tool for your command line. It helps you install, manage, and switch between different versions of development tools especially Java.

Why use SDKMAN? Instead of downloading zip files from websites and manually editing your system environment variables (like JAVA_HOME), SDKMAN does all the hard work automatically in your Terminal.

Step 1: Open Your Terminal

First, you need to open the Terminal application on your MacBook.

  • Press Command + Space to open Spotlight Search.
  • Type Terminal and press Enter.

Step 2: Install SDKMAN

To install SDKMAN, you just need to run one command. Copy the code below, paste it into your Terminal, and press Enter:

curl -s "https://get.sdkman.io" | bash

The script will download and set up SDKMAN on your system.

When it finishes, you must load SDKMAN so your Terminal recognizes it. You can either close and reopen the Terminal, or run this command:

source "$HOME/.sdkman/bin/sdkman-init.sh"

To check if it worked, type this:

sdk version

If you see a version number on your screen, SDKMAN is installed and ready!

Step 3: Install OpenJDK 26

Now, we will use SDKMAN to install Java. SDKMAN has a big list of Java versions from many different providers.

To see the full list of available Java versions, run:

sdk list java

Look in the list for OpenJDK and find version 26. The identifier will usually look like 26-open. (Note: If it is an Early Access version, it might look like 26.ea-open).

To install it, run this command:

sdk install java 26-open

SDKMAN will download OpenJDK 26 and configure it. If the Terminal asks you “Do you want this to be set as default?”, type Y (for Yes) and press Enter.

Step 4: Verify Your Java Version

Let’s make sure Java is working correctly. Run this command:

java -version

You should see text on your screen that says something like openjdk version "26".

Conclusion

Great job! You have successfully installed SDKMAN and OpenJDK 26 on your Mac.

The best part is that whenever you need to use an older or newer version of Java in the future, you do not need to do this setup again. You can just use SDKMAN to install and switch versions easily (for example: sdk use java 21-open).
