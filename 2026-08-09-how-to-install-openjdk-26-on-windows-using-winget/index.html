How to Install OpenJDK 26 on Windows Using Winget

Welcome back! In our previous post, we learned how to install Java on a Mac. Today, we will learn how to easily install OpenJDK 26 on a Windows computer. To do this, we will use a great tool built into Windows called winget.

This guide is written in simple English, making it easy for developers everywhere to understand and follow.

What is Winget?

Winget (Windows Package Manager) is a free command-line tool made by Microsoft.

Just like SDKMAN on macOS and Linux, winget helps you discover, install, update, and remove software on your Windows machine using only text commands. Instead of going to a website, downloading an .exe or .msi file, and clicking “Next” many times, winget does the whole installation process for you quickly in the background.

Step 1: Open Your Terminal

First, you need to open your command line app on Windows.

  • Click the Start Menu (or press the Windows key).

  • Type Terminal or PowerShell and press Enter.

Step 2: Search for OpenJDK 26

Because there are different versions of OpenJDK made by different companies (like Microsoft, Oracle, or Eclipse Temurin), it is a good idea to search for it first. This shows you the exact name you need to type to install it.

In your Terminal, run this command:

PowerShell

winget search "OpenJDK 26"

Winget will search its database and show you a list of results. Look at the column named Id. You will see IDs that look similar to these:

  • Microsoft.OpenJDK.26

  • Oracle.JDK.26

  • EclipseAdoptium.Temurin.26.JDK

Choose the one you prefer. Many developers use the Microsoft build or Eclipse Temurin because they are free and open-source.

Step 3: Install OpenJDK 26

Once you find the exact Id from the search step, you can install it. For this example, we will install the Microsoft Build of OpenJDK 26.

Run this command in your Terminal:

PowerShell

winget install Microsoft.OpenJDK.26

(Note: If you chose a different vendor in Step 2, just replace Microsoft.OpenJDK.26 with that specific ID).

A loading bar will appear on your screen. Winget will safely download the installer and run it for you. If a Windows pop-up asks if you want to allow this app to make changes to your device, click Yes.

Step 4: Verify Your Java Version

After the installation says “Successfully installed”, we need to check if Java is working.

Close your Terminal and open a new one (this step is important so Windows can load your new Java settings). Then, type this command:

PowerShell

java -version

If everything worked, you should see text on your screen saying openjdk version "26".

Conclusion

Great job! You have successfully used winget to find and install OpenJDK 26 on your Windows PC.

Winget makes it incredibly easy to manage software on Windows. You can use it to install almost any popular development tool you need in the future!
